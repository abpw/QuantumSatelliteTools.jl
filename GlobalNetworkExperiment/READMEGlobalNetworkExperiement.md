Julia QSAT:

    After that, this is what is currently being built in the my branch of the Julia simulator package. It should be noted that the TimeVariateNetworking directory is just a Julia version of the one found in python, but there's a seperate directory for the city lists and directory.

    A good place to start in this branch of the Julia simulator is in the directory ClusterCreating, specifically DistanceCalculations.jl. Here, have_R_sine() just calculated geodesic distance in km between two points in lat long form, and dist just makes this work for our city tuples. The ObjectiveFunction.jl needs a little more context. Essentially, I've choosen to combine a game-theoretic algorithm to count the number of cluster heads (Shapely Algorithm, which I will touch on later). In order to use said algorithm, I need an objective function which is normalized on (0,1] such that the closer two points d1 and d2 are (smaller their distance), the higher their objective_function(dist(d1,d2)) is. 

    The next step is to look at the ShapleyAlg.jl file. The Shapely algorithm is an algorithm that assigns cluster heads for a graph based on its objective function. The primary value of the Shapely Algorithm is the Shapely value, which in our case essentially denotes how good of a candidate a given node is for being a cluster head (a city which is surrounded by other cities in a dense way). The Shapely algorithm returns the cluster heads, and we use this number to determine the "k" in our k-means algorithm, which we end up just using Julia's Clustering Package's kmeans function (see KMeansAlg.jl).
