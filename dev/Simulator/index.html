Simulator

The Simulator namespace within the QuantumSatelliteTools.jl provides tools for simulating a quantum network over freespace optical channels.

Getting Started

Add the QuantumSatelliteTools.jl package using Julia's package manager:

] add QuantumSatelliteTools

Import the Simulator namespace into your Julia environment:

using QuantumSatelliteTools.Simulator

QuantumSatelliteTools.Simulator.build_optimized_constellation — Method

Build a synthetic constellation and initialize SGP4 propagators based on the optimized inclination angles and satellite allocations discovered in https://arxiv.org/abs/2603.02480. The five base orbits have inclination angles of 153.21, 24.72, 143.04, 69.94, and 149.05 degrees with 45, 37, 15, 1, and 2 satellites respectively.

Keyword Arguments

  • orbits: Number of orbits per inclination angle (default 10).

Returns

  • Vector{Propagator}: A vector of SGP4 propagators initialized with the generated TLEs.

QuantumSatelliteTools.Simulator.simulate_step — Method

Perform a single time step of the simulation, applying the evaluation function.

Keyword Arguments

  • nodes: vector of nodes (satellites and ground stations).

Returns
