AstronomyGeometry

The AstronomyGeometry namespace within the QuantumSatelliteTools.jl provides functionality for converting between coordinate systems and computing visibility and distance between objects described by those coordinate systems.

Getting Started

Add the QuantumSatelliteTools.jl package using Julia's package manager:

] add QuantumSatelliteTools

Import the AstronomyGeometry namespace into your Julia environment:

using QuantumSatelliteTools.AstronomyGeometry

QuantumSatelliteTools.AstronomyGeometry.ellipsoid_line_intersection — Method

Compute the intersection points between an ellipsoid and a line segment.

Arguments

  • major::Number: Semimajor axis of the ellipsoid.
  • minor::Number: Semiminor axis of the ellipsoid.
  • point1::Point3D: First point defining the line in the ECEF or ECI reference frame.
  • point2::Point3D: Second point defining the line in the ECEF or ECI reference frame.

Keyword Arguments

  • only_between::Bool: If true, only return intersections between point1 and point2.

Returns

  • A vector of 0, 1, or 2 intersection points as tuples in the same reference frame as the inputs (ECI or ECEF).

QuantumSatelliteTools.AstronomyGeometry.gs_gs_distance — Method

Compute the distance between two ground stations given in geodetic coordinates.

Arguments

  • gs1::GS: First ground station coordinates (geodetic latitude in radians, geodetic lon in radians[, height in meters]).
  • gs2::GS: Second ground station coordinates (geodetic latitude in radians, geodetic lon in radians[, height in meters]).

Returns

  • Distance between the ground stations in meters. Uses Euclidean distance if there is line of sight (one ground station must have positive height). Otherwise uses the haversine formula.
