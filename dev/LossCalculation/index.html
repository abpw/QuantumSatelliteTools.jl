AstronomyGeometry

The LossCalculation namespace within the QuantumSatelliteTools.jl provides tools for calculating different types of loss over a channel described by a FreespaceChannel object.

Getting Started

Add the QuantumSatelliteTools.jl package using Julia's package manager:

] add QuantumSatelliteTools

Import the LossCalculation namespace into your Julia environment:

using QuantumSatelliteTools.LossCalculation
