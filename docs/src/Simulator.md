# Simulator

The **Simulator** namespace within the [**QuantumSatelliteTools.jl**](index.md) provides tools for simulating a quantum network over freespace optical channels.

## Getting Started

Add the [**QuantumSatelliteTools.jl**](index.md) package using Julia's package manager:
```julia
] add QuantumSatelliteTools
```

Import the **Simulator** namespace into your Julia environment:
```julia
using QuantumSatelliteTools.Simulator
```
