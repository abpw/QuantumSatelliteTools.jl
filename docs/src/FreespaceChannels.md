# AstronomyGeometry

The **FreespaceChannels** namespace within the [**QuantumSatelliteTools.jl**](index.md) provides the type FreespaceChannel, which contains the information necessary to compute transmissivities.

## Getting Started

Add the [**QuantumSatelliteTools.jl**](index.md) package using Julia's package manager:
```julia
] add QuantumSatelliteTools
```

Import the **FreespaceChannels** namespace into your Julia environment:
```julia
using QuantumSatelliteTools.FreespaceChannels
```
