# AstronomyGeometry

The **LossCalculation** namespace within the [**QuantumSatelliteTools.jl**](index.md) provides tools for calculating different types of loss over a channel described by a [`FreespaceChannel`](FreespaceChannels.md) object.

## Getting Started

Add the [**QuantumSatelliteTools.jl**](index.md) package using Julia's package manager:
```julia
] add QuantumSatelliteTools
```

Import the **LossCalculation** namespace into your Julia environment:
```julia
using QuantumSatelliteTools.LossCalculation
```
