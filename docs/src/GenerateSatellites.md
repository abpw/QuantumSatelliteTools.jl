# AstronomyGeometry

The **GenerateSatellites** namespace within the [**QuantumSatelliteTools.jl**](index.md) provides tools for generating vectors of [`TLE`](https://juliaspace.github.io/SatelliteToolboxTle.jl/stable/) or [satellite propagator](https://juliaspace.github.io/SatelliteToolboxPropagators.jl/stable/) objects.

## Getting Started

Add the [**QuantumSatelliteTools.jl**](index.md) package using Julia's package manager:
```julia
] add QuantumSatelliteTools
```

Import the **GenerateSatellites** namespace into your Julia environment:
```julia
using QuantumSatelliteTools.GenerateSatellites
```
