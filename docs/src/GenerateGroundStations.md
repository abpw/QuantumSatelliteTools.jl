# AstronomyGeometry

The **GenerateGroundStations** namespace within the [**QuantumSatelliteTools.jl**](index.md) provides functions for producing vectors of ground station coordinates.

## Getting Started

Add the [**QuantumSatelliteTools.jl**](index.md) package using Julia's package manager:
```julia
] add QuantumSatelliteTools
```

Import the **GenerateGroundStations** namespace into your Julia environment:
```julia
using QuantumSatelliteTools.GenerateGroundStations
```
