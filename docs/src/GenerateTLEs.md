# AstronomyGeometry

The **GenerateTLEs** namespace within the [**QuantumSatelliteTools.jl**](index.md) provides tools for generating vectors of [`TLE`](https://github.com/JuliaSpace/SatelliteToolboxTle.jl) objects.

## Getting Started

Add the [**QuantumSatelliteTools.jl**](index.md) package using Julia's package manager:
```julia
] add QuantumSatelliteTools
```

Import the **GenerateTLEs** namespace into your Julia environment:
```julia
using QuantumSatelliteTools.GenerateTLEs
```
